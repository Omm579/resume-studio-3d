## 🛠️ &nbsp;Tech Stack

<div align="center">

| Layer | Technology | Why |
|:---|:---|:---|
| **Framework** | Next.js 15 (App Router) | SSR, file-based routing, edge-ready |
| **3D Graphics** | React Three Fiber + Three.js | Declarative 3D, React-native feel |
| **Animations** | Framer Motion | Physics-based, buttery smooth |
| **Styling** | Tailwind CSS | Utility-first, zero dead CSS |
| **Icons** | Lucide React + React Icons | Consistent, tree-shakable |
| **Font** | Geist (via `next/font`) | Vercel's modern, optimized typeface |

## 🚀 &nbsp;Getting Started

> Clone it. Install it. Run it. You'll be up in under two minutes.

**1. Clone the repo**
```bash
git clone https://github.com/your-username/resume-3d-studio.git
cd resume-3d-studio
```

**2. Install dependencies**
```bash
npm install
# or
yarn install
# or
pnpm install
```

**3. Start the dev server**
```bash
npm run dev
```

**4. Open your browser**

Visit [http://localhost:3000](http://localhost:3000) and start building.

> 💡 Edit `app/page.tsx` to start customizing. Hot reload means you'll see changes instantly — no manual refresh needed.

## 📁 &nbsp;Project Structure

```
resume-3d-studio/
├── app/                    # Next.js App Router pages & layouts
│   ├── layout.tsx          # Root layout with font + providers
│   ├── page.tsx            # Landing page entry point
│   └── builder/            # Resume builder routes

│   ├── ui/                 # Shared design system components
│   └── tools/              # ATS calculator, AI cover letter
├── lib/                    # Utilities, hooks, store logic
├── public/                 # Static assets

```
